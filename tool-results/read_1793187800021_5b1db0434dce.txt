    89→### How `passedRatio` was computed
    90→```ts
    91→const passedRatio = useMemo(() => {
    92→  const source = evaluation?.rubricScores || rubric || EMPTY_RUBRIC;
    93→  const sum = rubricSum(source); // problemSolving + cleanCode + optimization + communication + edgeCases
    94→  return Math.round((sum / 50) * 100);
    95→}, [evaluation, rubric]);
    96→```
