   - **WebRTC signaling relay:** `webrtc:offer`, `webrtc:answer`, `webrtc:ice-candidate` — each relays via `userSocketByUserId` lookup; if the target userId isn't connected the event is silently dropped (no crash).
   - **System:** console logs for connect/disconnect/join/leave, `server:shutdown` broadcast on graceful SIGTERM/SIGINT, then `io.close()` + `httpServer.close()` + `process.exit(0)`.
